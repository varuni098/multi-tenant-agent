# Acme style guide

Internal guidance for Acme's own pages. Only Acme users can see this document.

## Dashboard

The Acme dashboard always uses the dark theme so that the wall screens in the operations
room stay readable at night. Do not switch it to light.

## Login page

Keep the login page on the light theme and in English. Marketing reviews any change to the
login page first.

## Brand colour

Acme is on the free plan, so custom brand colours are not available. Use the default
accent colour until the pro plan upgrade is approved.
