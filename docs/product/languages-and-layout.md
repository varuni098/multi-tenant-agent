# Languages, layout and tips

## Language

The `language` setting controls the page's interface language. Supported language codes are
`en` (English), `es` (Spanish), `fr` (French) and `de` (German). Other languages, such as
Italian, aren't supported yet and are rejected.

Set the language per page ("Set the dashboard language to French") or for the whole tenant
by not naming a page.

## Layout

The `layout` setting controls density. `comfortable` adds more spacing and is the default.
`compact` fits more content on the screen, which suits dashboards.

## Onboarding tips

`show_tips` turns onboarding hints on or off. It accepts true or false, and also yes, no,
on, off, enabled and disabled.
